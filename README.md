🧮 Java Calculator

Welcome to the Java Calculator project! This application is a simple, efficient, and user-friendly calculator developed using Java to perform essential arithmetic operations. It provides an interactive console-based interface where users can input two numbers, select a mathematical operation, and instantly receive the calculated result. The project demonstrates the implementation of core Java programming concepts such as object-oriented programming (OOP), user input handling, conditional statements, switch-case, methods, and arithmetic operations, making it an excellent learning resource for beginners.

✨ Features
➕ Addition
➖ Subtraction
✖️ Multiplication
➗ Division (with divide-by-zero validation)
🟰 Modulus Operation

🎯 Project Objective

The primary objective of this project is to strengthen fundamental Java programming skills by building a practical and real-world application. It showcases the use of decision-making statements, methods, loops, user input processing, and mathematical operations while emphasizing clean coding practices and logical problem-solving. This project is suitable for students, beginners, and anyone looking to understand the basics of Java application development through a simple yet meaningful project.
